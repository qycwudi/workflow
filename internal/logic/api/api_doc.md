## 请求示例

```bash
curl -X POST http://127.0.0.1:8888/123 \
  -H 'Content-Type: application/json' \
  -d '{
    "input": "帮我写一个生日祝福语",
    "obj": { "name": "name示例" },
    "bl": true,
    "arr_str": ["示例1", "示例2"]
  }'
```
